# 微信小程序真机隐私能力配置

`miniapp/src/privacy.json` 只是仓库内的审计清单，微信不会读取或发布这个文件。真机能力必须在当前 AppID 对应的微信公众平台后台声明。

## 后台操作

1. 使用当前小程序管理员账号登录 `https://mp.weixin.qq.com/`。
2. 进入「设置」→「服务内容声明」→「用户隐私保护指引」。不同后台版本也可能显示为「设置」→「基本设置」→「服务内容声明」。
3. 添加并填写以下信息：

| 信息类型 | 建议用途文案 |
| --- | --- |
| 剪切板 | 用于复制政策官网链接、审查报告和沟通文本，以及读取用户主动复制的合同正文 |
| 选中的照片或视频信息 | 用于入住验房和退租证据照片（仅保存在本机）；如用户选择对合同拍照或从相册选择合同图片进行 OCR 识别，将在用户逐次确认后上传服务端识别文字，原始图片仅在内存中处理，不写入磁盘、不持久化保存，请求处理结束后释放相关内存 |
| 摄像头 | 用于拍摄入住验房照片（仅保存在本机）；如用户选择对合同拍照进行 OCR 识别，将在用户逐次确认后上传服务端识别文字，原始图片仅在内存中处理，不写入磁盘、不持久化保存，请求处理结束后释放相关内存 |
| 选中的文件 | 用于从微信聊天或文件传输助手选择文件：TXT/MD 合同和证据附件仅保存在本机；DOCX/PDF 合同将在用户逐次确认后上传服务端提取文字，原始文件仅在内存中处理，不写入磁盘、不持久化保存，请求处理结束后释放相关内存 |

4. 如正式版本开放联网 AI，还需如实补充：用户主动提交的问题、可选统计摘要、租小审服务端、实际模型服务商、处理目的及保存期限。联网 AI 默认优先使用，首次发送联网请求前单独征得用户同意；用户拒绝、未授权或服务不可用时使用本地分析，不能以本地功能的授权替代联网处理同意。

5. 保存并提交隐私保护指引。
6. 回到微信开发者工具，重新编译并上传/生成新的体验版二维码。旧体验版不会自动获得新声明。
7. 在手机微信中删除旧的小程序使用记录或从最近使用中移除，再扫描新体验版二维码测试。

## 重要说明

- `scope.album` 不是微信有效的授权 scope；选择相册照片应直接调用 `chooseImage`，由微信隐私授权流程处理。
- `scope.writePhotosAlbum` 只用于把文件写入系统相册。本项目不执行这一操作，因此不应为了“选图”而声明它。
- 手机微信里的「小程序设置」只能管理已经触发并允许用户控制的权限，不能代替公众平台的开发者声明。
- 如果当前使用的是开发者工具自动提供的测试号，并且后台没有「用户隐私保护指引」入口，需要改用已注册且自己拥有管理员权限的小程序 AppID。

## 真机验收

- 补贴页可复制官网链接。
- 合同页可读取剪贴板中的正文，并能从微信聊天选择 TXT/MD。
- 合同页选择 DOCX/PDF 时会提示需上传服务端提取文字，用户确认后才上传；原始文件仅在服务端内存中处理，不写入磁盘、不持久化保存，请求处理结束后释放相关内存。
- 合同页选择拍照或相册合同时会提示需上传服务端 OCR 识别，用户确认后才上传；原始图片仅在服务端内存中处理，不写入磁盘、不持久化保存，请求处理结束后释放相关内存。
- 验房页"拍照"只打开相机，"相册"只打开相册，验房照片仅保存在本机。
- 证据包可从相册添加图片，也可从微信聊天选择文件，证据附件仅保存在本机。
- 联网 AI 默认优先使用，首次发送联网请求前单独征得用户同意；用户拒绝、未授权或服务不可用时使用本地分析。联网 AI 默认不发送合同全文、照片和附件。
- 合同页在“开始综合审查”按钮旁披露处理范围；用户点击后即主动发起本地规则与 AI 协作，双重脱敏合同文字会发送至租小审服务端和模型服务商，照片和附件原文件不发送。
- 首次使用上述能力时出现租小审自己的隐私授权弹层；同意后原操作继续执行。
