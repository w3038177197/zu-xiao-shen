# 小程序人工冒烟验收清单

> 本清单用于真机环境验收，静态冒烟测试见 `scripts/smoke-miniapp.mjs`（`npm run smoke:miniapp`）。
> 本机未安装微信开发者工具 CLI（miniprogram-automator），无法做 IDE 自动化；以下真机专属能力不伪造，必须用真实微信环境验证。

## 环境准备

- 设备：iPhone + Android 各一台
- 微信版本：记录实际版本号
- 基础库版本：记录实际版本号
- 小程序版本：体验版二维码
- 验收前：删除旧的小程序使用记录，避免缓存旧隐私授权

## 失败处理

- 任何一项失败：保留截图、控制台日志和复现步骤
- 失败项不视为"通过"，修复后重新验收
- 真机专属能力（相机、相册、微信隐私授权、文件选择、分享）不能用开发者工具模拟器代替

---

## 1. 首页首次进入

### 空数据首次进入

- [ ] 扫码进入首页，显示品牌"租小审"和"租房风险助手"
- [ ] 显示“当前房源”卡片，默认房源名称可见，“管理”按钮不挤压、不竖排
- [ ] 当前步骤显示"开始审查合同"，引导文案"先把合同风险看懂"
- [ ] 三步走区域显示审合同、入住留证、退租证据，状态均为"未开始"
- [ ] "问租房 AI"入口可见
- [ ] "住房补贴匹配"入口可见
- [ ] "隐私与数据"入口可展开

### 已有数据进入

- [ ] 录入合同草稿后返回首页，当前步骤显示"继续审查合同"
- [ ] 完成验房后返回首页，当前步骤显示"继续入住验房"或"入住拍照留证"
- [ ] 整理证据后返回首页，当前步骤显示"继续整理退租证据"
- [ ] 新建第二个房源后切换，合同、验房和证据包数据不串到原房源
- [ ] 清除当前房源只清当前房源资料，其他房源资料仍可切回查看

## 2. 合同审查

### 空数据

- [ ] 进入审查页，输入框显示引导"粘贴正文，或导入 TXT、MD、DOCX、PDF…"
- [ ] 合同页不显示"拍照识别"和"相册识别"；粘贴正文后，标题右侧显示"清空"
- [ ] 点击"清空"先弹确认；确认后正文、字数和当前审查结果清空，重新进入页面也不会恢复旧草稿
- [ ] "手机粘贴"按钮可点击
- [ ] "载入演示合同"可选并载入
- [ ] 未粘贴时点击"开始审查"，提示"请先粘贴或导入合同"

### 已有数据

- [ ] 粘贴或载入合同后点击“开始综合审查”，显示风险评分和风险卡片
- [ ] 点击“开始综合审查”不再弹出单独的合同全文授权框；按钮旁明确提示脱敏合同文字将用于 AI 核验
- [ ] 综合审查直接合并本地规则和 AI 补充结果，结果区不再显示“让 AI 解读审查结果”按钮
- [ ] 审查记录入口可见，可查看历史
- [ ] 逐条采纳和全部采纳可用

### 真机专属（不伪造）

- [ ] 微信聊天文件选择 TXT/MD：弹出 chooseMessageFile，选择后正文填入
- [ ] “选择文件/最近文件”可从微信聊天、文件传输助手或最近文件选择；手机任意目录中的文件需先分享到微信
- [ ] DOCX/PDF：弹出"需上传服务端提取文字"确认，确认后上传并解析

## 3. 入住验房

### 空数据

- [ ] 进入验房页，显示房型选择和房间列表
- [ ] 验房页不再显示 TXT、复制完整报告或 AI 解读按钮，统一从首页导出 Word

### 已有数据

- [ ] 选择房间，逐项检查并标记状态
- [ ] 记录瑕疵后，统计显示已检查/总项数、瑕疵数、照片数
- [ ] 生成报告后可复制房东沟通话术

### 真机专属（不伪造）

- [ ] 拍照：弹出相机授权，拍照后照片保存到本机
- [ ] 相册：弹出相册授权，选择后照片保存到本机
- [ ] 相册可一次选择多张，数量不超过当前检查项剩余上限
- [ ] 照片预览可放大查看
- [ ] 删除照片后，小程序本地文件同步清理
- [ ] 已保存照片提示与“只清照片”按钮保持同一行或正常换行，不出现逐字竖排和大片空白
- [ ] 未检查项默认收起，点击“开始记录”后再展开状态、备注和照片控件

## 4. 证据包

### 空数据

- [ ] 进入证据包，各附件组显示"该组暂无附件"
- [ ] "让 AI 优化这段话"按钮禁用，提示"暂无证据资料可优化"

### 已有数据

- [ ] 录入退租信息、勾选证据清单后，统计更新
- [ ] 添加附件后，附件数显示
- [ ] "让 AI 优化这段话"按钮可用

### 真机专属（不伪造）

- [ ] 从相册添加图片：弹出相册授权
- [ ] 从相册一次选择 2 至 9 张图片，全部添加且只保存一次记录
- [ ] “选择文件/最近文件”：弹出 chooseMessageFile，可一次选择最多 9 个支持的文件
- [ ] 手机任意目录中的文档先分享到微信、文件传输助手或最近文件，再从小程序选择
- [ ] 生成本地沟通说明后，点击“让 AI 优化这段话”直接在当前页显示结果，不跳转 AI 页面
- [ ] 联网失败时保留本地草稿并显示“重试联网”；点击“采用这版”后写回沟通说明输入框
- [ ] 证据页只保留保存，Word 报告统一从首页“报告导出中心”生成

## 5. 补贴匹配

- [ ] 进入补贴页，显示"补贴匹配"和"毕业生租房补贴线索匹配"
- [ ] 城市关键词搜索可用，只显示已收录政策的城市
- [ ] 个人情况输入框可填写，空数据时提示"请填写真实情况后再查看匹配判断"
- [ ] 填写后自动显示满足/待确认/不满足数量
- [ ] 点击政策可复制官网链接
- [ ] "让 AI 解释匹配结果"可用
- [ ] 联网失败时显示"本地降级"和"重试联网"

## 6. AI 本地降级

### 联网正常

- [ ] 进入 AI 页，底部提示"优先联网 AI · 失败自动本地回答"
- [ ] 首次发送前弹出联网授权确认
- [ ] 同意后发送问题，返回联网回答，标记"AI生成"
- [ ] 复制回答时自动附加 AI 内容提示
- [ ] 明确说“我是房东”时按房东视角回答；“房东要扣我押金”仍按租客视角回答
- [ ] 回复默认两个短段落，不出现 `*`、`#`、反引号或 Markdown 标题
- [ ] 问“这个怎么办”一类模糊问题时只追问一个关键信息，不猜测合同或事实
- [ ] AI 不得声称看过未发送的合同全文、照片画面或附件文件

### 拒绝/未授权/不可用

- [ ] 首次授权弹窗选择"拒绝"：返回本地回答，提示"联网授权未完成，本次已使用本地回答"
- [ ] 撤销联网授权：提示"已撤销联网授权，下次发送前会再次询问"
- [ ] 关闭网络后发送：返回本地回答，提示"联网失败，已本地回答"，出现"重试联网"
- [ ] 额度耗尽：提示"今日额度已用完"，返回本地回答

### 资料摘要

- [ ] 默认不发送合同全文、照片、附件
- [ ] 开启资料摘要后，可逐模块选择合同审查、验房、证据包、补贴
- [ ] 发送前可预览实际文本

## 7. Word 报告与数据备份

- [ ] 首页“报告导出中心”可单选合同分析、入住验房、证据包汇总并生成组合 Word
- [ ] “一键导出全部”生成 ZIP，内含 3 份独立 Word；验房和证据图片可嵌入对应报告
- [ ] 证据包 ZIP 含证据包清单.json，照片、附件和文本摘要均有 SHA-256 指纹
- [ ] 首页“高级数据管理”可生成恢复用 Word 备份、导入 Word/ZIP 备份、清理无用文件和清除全部数据
- [ ] 导入备份显示摘要弹窗“确认恢复备份”，说明“恢复将覆盖当前本机资料”
- [ ] 恢复成功后记录写回本机
- [ ] 清除当前房源：弹窗确认后只清除当前房源的合同、验房、证据包、补贴和 AI 对话
- [ ] 清除全部数据：弹窗确认后清除全部房源、照片、附件、AI 对话、合同原文、审查记录和本地导出文件

## 8. 重启后数据持久化

- [ ] 录入合同、验房、证据后关闭小程序
- [ ] 重新打开，所有数据仍在
- [ ] 照片和附件仍可读取

## 9. 微信隐私授权（真机首次）

- [ ] 首次使用剪切板：出现租小审隐私授权弹层
- [ ] 首次使用相机：出现微信相机授权 + 租小审弹层
- [ ] 首次使用相册：出现微信相册授权 + 租小审弹层
- [ ] 首次选择微信文件：出现租小审弹层
- [ ] 首次联网 AI：出现联网授权弹层（单独，不与其他授权合并）
- [ ] 拒绝授权后：对应功能不可用，但不影响其他本地功能
