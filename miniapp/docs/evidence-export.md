# 退租证据包导出说明

证据包页面提供三种真实导出方式，全部在小程序本机生成，不会为了导出把资料上传到服务器。

## 导出格式

- `ZIP 完整证据包`：包含证据摘要、JSON 清单以及当前仍能读取的真实附件和模块引用。附件按“合同文件、房屋照片、沟通记录、费用凭证”分类。
- `PDF 证据摘要`：多页 A4 摘要，使用 PDF 中文字体映射，适合预览、打印和发送。
- `TXT 证据摘要`：UTF-8 纯文本，作为兼容性最高的兜底格式。

## 可靠性约束

- ZIP 在本机采用无损存储模式生成，不压缩图片，避免引入大体积压缩依赖；附件合计上限为 35MB。
- 导出前逐个读取附件。文件丢失时不会伪装成成功收录，而是在导出结果中提示遗漏数量，并写入 `证据包清单.json`。
- 同名附件自动追加序号，避免覆盖。
- PDF、ZIP 或 TXT 写入成功但分享面板打开失败时，文件仍保留在小程序本地，并提示检查微信版本和网络后重试。
- 用户取消分享不视为文件生成失败。

## 真机验收

1. 分别添加相册图片、微信文件和其他模块引用。
2. 导出 ZIP，发送到文件传输助手后解压，核对目录、摘要、JSON 清单和附件内容。
3. 导出 PDF，确认中文、分页、金额和沟通说明可阅读。
4. 删除一个已被系统清理的本地附件后再次导出，确认页面明确提示该附件未打包。
5. 超过 35MB 时应提示删减大文件，页面不白屏且原证据记录不变。
