# 退租证据包导出说明

证据页负责整理和保存资料，正式导出统一在首页“报告导出中心”完成，文件只在小程序本机生成。

## 导出格式

- 单独勾选“证据包汇总”：生成一份 A4 Word，包含清单、附件来源、日期和当前可读取的证据图片。
- “一键导出全部”：生成 ZIP，内含合同分析、入住验房和证据包汇总三份独立 Word。
- “生成恢复用备份”：用于迁移和恢复全部本机工作状态，不作为展示报告。

## 可靠性约束

- 图片合计上限为 35MB，超过上限或本地文件丢失时会在 Word 中明确记录遗漏。
- 同一份组合报告中的验房照片和证据图片共享 35MB 上限。
- Word 或 ZIP 写入成功但分享面板打开失败时，文件仍保留在小程序本地。
- 用户取消分享不视为文件生成失败。

## 真机验收

1. 分别添加相册图片、微信文件和其他模块引用。
2. 返回首页单独导出证据包 Word，核对附件清单、日期、图片和中文排版。
3. 一键导出全部并发送到文件传输助手，解压后确认有三份独立 Word。
4. 删除一个本地附件后再次导出，确认 Word 明确提示该图片未嵌入。
5. 超过 35MB 时应提示删减大文件，页面不白屏且原证据记录不变。
