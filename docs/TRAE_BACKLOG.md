## P0：需要用户操作

### 1. 配置生产额度持久化

目标：将微信云托管额度存储从 memory 切换为 redis-rest。

用户操作：

- 在微信云托管环境变量中填写 UPSTASH_REDIS_REST_URL 和 UPSTASH_REDIS_REST_TOKEN。
- 不要把 Redis 凭据写进仓库、截图或聊天记录。
- 重新部署微信云托管服务。

验收命令：

~~~powershell
$env:MINIAPP_DEPLOY_REQUIRE_PERSISTENT='1'
npm run check:miniapp-deployment
~~~

完成标准：输出包含“额度存储：redis-rest（可跨重启）”和“额度存储探测：可读写”，命令退出码为 0。

### 2. 微信公众平台隐私指引终核

目标：确认微信后台已如实披露当前真实行为。

必须核对：

- DOCX/PDF 合同会在用户逐次确认后上传服务端提取文字。
- 合同拍照/相册 OCR 会在用户逐次确认后上传服务端识别文字。
- 验房/证据照片仅本机保存。
- 联网 AI 首次发送前单独征得用户同意；拒绝、未授权或服务不可用时本地降级。
- 模型服务商的数据处理范围已披露。

### 3. iPhone + Android 真机回归

必须覆盖：

- 相机、相册、微信聊天文件、剪贴板。
- TXT/MD/DOCX/PDF 导入、合同 OCR、联网 AI、额度耗尽、本地降级。
- 弱网取消、重试联网、重启后照片恢复。
- TXT/PDF/ZIP 分享、备份导入导出、清除全部数据。

记录要求：机型、微信版本、基础库版本、结果、失败截图和复现步骤。
