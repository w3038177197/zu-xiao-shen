# 合同审查对抗评测

这套评测使用完全虚构的租房合同，不包含真实姓名、地址或交易数据。它的用途是检查本地合同审查规则能否在不同写法下召回风险，不是法律意见，也不是把合同正文加入法律知识库。

## 当前覆盖

- 24 类租房合同高频风险
- 每类 3 种不同措辞
- 6 份每份 12 个风险的组合合同
- 1 份根据实际漏检样本脱敏整理的 12 风险合同
- 1 份规范合同对照样本，用于检查误报
- 每条结果要求保留合同原文证据、修改建议和替代条款

## 命令

```text
npm run test:contract-review-benchmark
npm run generate:contract-review-cases -- --count=10 --risks=12 --seed=20260731
```

相同 `seed` 会生成完全相同的合同，便于复现漏检；换一个 `seed` 会重新组合风险和措辞。生成的 TXT 和 manifest 位于 `generated-reports/contract-review/`，该目录已被忽略，不会进入版本提交。

## 结果解释

`110/110 expected risks recalled` 只证明本地规则对这批已知风险全部召回，不代表法律审查绝对完整。真实合同仍可能有新写法、扫描/OCR 错字、附件冲突和地域政策差异。

当前小程序的联网 AI 默认只接收审查摘要和风险点，不接收合同全文。要让远程模型直接复核全文，必须单独增加用户确认、隐私披露、服务端限长和上传失败处理，不能把这套评测合同直接当作模型微调结果。

拿到真实失败样本时，应先去除姓名、手机号、身份证号、精确地址和账号，再补充：风险标签、合同原文证据、期望是否报警。该样本通过后才加入黄金集。
